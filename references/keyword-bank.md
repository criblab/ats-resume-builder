## Soft skills: use sparingly

Soft skills are inferred from evidence, not listed. If the JD insists, attach them to proof:

- "Mentored 3 engineers" beats "strong mentoring skills".
- "Aligned 4 teams on a shared schema" beats "excellent communication".
- "Presented the migration plan to 30 stakeholders" beats "stakeholder management".

## Title mirrors

| If the JD says | Consider using (only if accurate) |
| :--- | :--- |
| Senior Backend Engineer | Senior Software Engineer (Backend) |
| Full-Stack Developer | Full-Stack Software Engineer |
| DevOps Engineer | Platform / DevOps Engineer |
| SRE | Site Reliability Engineer |
| Data Engineer | Data Platform Engineer |
| ML Engineer | Machine Learning Engineer |
| Tech Lead | Technical Lead / Staff Engineer |

Never inflate a title. Mirror the function, not a promotion.
